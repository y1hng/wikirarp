# WikiRarp 🎯

A fast, lightweight ARP network scanner and Python library designed for Linux infrastructure penetration testing and network mapping.

Created and maintained by [wikirity](https://github.com/y1hng).

## Features

- **High Speed**: Multi-threaded ARP scanning built on Python's `concurrent.futures`.
- **Dual Usage**: Use it directly from your terminal as a CLI tool or import it as a library in your Python security scripts.
- **Clean Output**: Structured color-coded CLI output.

## Installation

Clone the repository and install it locally using `pip`:

```bash
git clone [https://github.com/y1hng/wikirarp.git](https://github.com/y1hng/wikirarp.git)
cd wikirarp
sudo pip install .
